# Student Management System

## Overview

The Student Management System is a menu-driven Python application that manages student records using a list of dictionaries.

Each student record contains:

- Student ID
- Name
- Age
- Course
- Marks

The application allows users to manage student information through a simple command-line interface.

---

## Features

- Add Student
- View All Students
- Search Student by ID
- Search Student by Name
- Update Student Details
- Delete Student
- Prevent Duplicate Student IDs
- User-Friendly Menu
